# Phasmo Помощник

Статический сайт-помощник для Phasmophobia: журнал призраков, фильтрация по уликам, скорости охоты, порогам рассудка и режимам контракта (3/2/1/0 улик, Mimic).

Один файл `index.html`, без сборки и зависимостей. Данные: патч июля 2026 (GameSpot, phasmophobia.su).

## Деплой на Vercel
1. Залей папку в GitHub-репозиторий.
2. На vercel.com: Add New → Project → выбери репозиторий.
3. Framework Preset: **Other**, Build Command и Output Directory оставь пустыми. Deploy.

## Локально
Открой `index.html` в браузере.
